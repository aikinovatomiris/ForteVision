# ForteVision

Локальный помощник для просмотра кассовых видео: загрузка MOV/MP4/M4V, анализ на ноутбуке, таймкоды, реальные JPEG-кадры и нормативные ссылки для ручной проверки. Видео не отправляются в облачные AI-сервисы; распознавания лиц нет.

## Статус сдачи

**Программная цепочка работает, но надёжный автоматический детектор нарушений пока не готов.** Активная модель `action_states_v8` показывает гипотезы в режиме `needs_review`. Отсутствие гипотез не доказывает, что запись нормальная. Публичный адрес и доступ жюри с другой сети пока не настроены.

- Размечены выборочные кадры всех 40 уникальных роликов: 528 кадров и 119 рамок крупных объектов. Это не полная покадровая разметка удостоверений, ключей или запирания.
- Обучены классификаторы событий и состояния рабочего места/клиента. Неудачные новые детекторы сохранены отдельно и не подключены.
- На проверке по отложенным группам 32 видео прежний детектор выделил 10 из 16 положительных роликов и ошибочно отметил 11 из 16 нормальных; правильный тип на положительных роликах не определён. Повышение порога ухудшило полноту. Эти данные ранее просматривались, поэтому это не независимый тест нового ракурса.
- В рабочем режиме неподтверждённые гипотезы сохраняются для проверки с прежними таймкодами и кадрами. Это воздержание от автоматического вывода, а не улучшение точности.

Фактические проверки: [VALIDATION.md](VALIDATION.md). Подробная история и ограничения: [релиз](docs/RELEASE_2026-10-18.md). Требования для сдачи: [JURY.md](docs/JURY.md).

## Быстрый запуск на подготовленном ноутбуке

```powershell
.\.venv\Scripts\python.exe -B -m scripts.preflight
.\.venv\Scripts\python.exe -B -m scripts.serve
```

UI: http://127.0.0.1:8501/ — API: http://127.0.0.1:8000/.
Остановить сервер — Ctrl+C. Для доступа в одной локальной сети: `powershell -File scripts/start_laptop.ps1 -ListenAddress 0.0.0.0`. Ноутбук должен оставаться включённым; LAN-доступ сам по себе не создаёт публичный HTTPS-адрес.

## Новая установка

Целевое окружение: Python 3.11/3.12 x64; Docker использует Python 3.11. Текущий ноутбук дополнительно проверен с Python 3.13.14 и другим установленным PyTorch; это не инструкция устанавливать закреплённые зависимости в произвольную версию Python.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m scripts.init_env
```

Передать из доверенной локальной сборки три файла в `models/`: `action_states_v8.joblib`, `action_states_v8.json`, `resnet18-f37072fd.pth`. Модели, видео и секреты намеренно отсутствуют в Git. Один `git clone` не содержит обученных весов. Joblib загружайте только из доверенного источника: этот формат может исполнять код. `scripts.init_env` создаёт случайный API-ключ без вывода в терминал и не перезаписывает существующий `.env`.

Затем выполнить `scripts.preflight` и `scripts.serve`, как выше. Официальные backbone-веса отдельно можно подготовить командой `python -m scripts.prepare_weights`; это не обучает классификатор событий. Скрипты обучения требуют локальных видео, разметки и промежуточных артефактов; они не скачивают частные данные.

## API и результаты

1. `POST /api/v1/analyze`, multipart `file`, заголовок `X-API-Key` → `202 {"job_id":"..."}`.
2. `GET /api/v1/jobs/{job_id}` с тем же ключом → `processing`, `done` или `failed`.
3. При `done` читать **assessment_status, review_required, review_candidates и analysis_complete**. В текущем режиме `verdict=no_violation` — только отсутствие автоматического вывода, **не подтверждение чистой записи**. Старое бинарное поле сохранено для совместимости; потребитель только этого поля не поддерживает режим проверки.

`review_candidates` содержит тип гипотезы, `timecode_sec`, контекст, 1–3 JPEG в base64 и при наличии `rule_references`. Нормативная ссылка не подтверждает правильность распознавания. Ошибка/таймаут остаётся `failed`. Общий бюджет API — 295 секунд с загрузкой и очередью; это не гарантия успешного анализа любого видео.

## Проверки и сборка

```powershell
python -m pytest -q -p no:cacheprovider
python -m scripts.preflight
python -m scripts.check_api --video "C:/path/to/allowed.mov"
python -m scripts.export_bundle --output artifacts/fortevision-laptop.zip
```

Локальный ZIP включает исходники Git и только активные доверенные веса; не включает `.env`, видео, кадры, SQLite и экспериментальные большие модели. SHA-256 перечислены внутри. Архив предназначен для передачи команде отдельно от GitHub.

Docker: `docker compose up -d --build` после подготовки `.env` и моделей. Compose использует активный классификатор и не запускает экспериментальный VLM. Подробнее: [развёртывание](docs/DEPLOYMENT.md), [хранение данных](docs/DATA_RETENTION.md), [лицензии](LICENSES.md).

## Состав проекта

- `app/` — FastAPI, Streamlit, очередь, SQLite, TTL, аутентификация и JPEG-валидация.
- `ml/` — локальные признаки, временные окна, обученные состояния, гипотезы и режим ручной проверки.
- `configs/` — нормативный контекст и аудит источников; `research/` — справочник.
- `scripts/` — запуск, обучение, оценка, диагностика и упаковка.
- `tests/` — программные проверки; число пройденных тестов не является метрикой качества распознавания.
