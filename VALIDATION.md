Рабочая машина: Windows, CPython **3.12.14**. Целевая конфигурация проекта/Docker — Python 3.11; отдельный прогон на 3.11 пока не выполнен.

- `python -m compileall -q app ml scripts tests` — успешно.
- `python -m pytest -q` — **27 passed**, без пропусков. Предупреждения зависимостей: deprecated AnyIO BlockingPortal alias в Starlette; SciPy игнорирует устаревшую solver option `iprint` из scikit-learn. Ошибок тестов нет.
- Разметка реально прочитана: 42 записи, 22 положительные, 20 отрицательных; все 42 MOV найдены. Метаданные OpenCV: длительность 11.633–142.533 с; все размеченные timestamps внутри длительности. Отчет — `artifacts/video_metadata.json`.
- Найдены две группы точных SHA-256 дубликатов: Х-4/Х-47 и Х-5/Х-48. Первый дубликат содержит две annotations — 57 и 68 с. Manifest объединяет разметку до split: **40 уникальных видео, 24 train / 8 validation / 8 test**. В unit test проверяется сохранение нескольких annotations при дедупликации.
- `python -m scripts.contact_sheets` — созданы все **22 JPEG** и metadata JSON. Все JPEG повторно декодированы, размер 960×660. Кадры сохранены только в `research/contact_sheets/`. Изображения не передавались внешним сервисам и не интерпретировались как доказательства конкретных типов нарушений.
- Реальные MOV выявили ненадежный seek и отрицательный preroll. Реализовано последовательное извлечение evidence и пропуск preroll без сдвига временной шкалы; добавлены regression tests.
- Полное последовательное декодирование всех **40 уникальных видео** завершилось без ошибок; максимум 10.63 с на видео (это не время полного ResNet18 inference). Отчет — `artifacts/decode_audit.json`.
- Реальный `X-1.mov` отправлен через FastAPI TestClient с настоящим subprocess worker и отсутствующим classifier. POST вернул 202, job завершился **failed** с понятной ошибкой, временный upload удален. Фиктивного `no_violation` нет.
- Официальный `resnet18-f37072fd.pth` скачан и проверен по hash prefix; сохранен полный SHA-256 и URL в `models/resnet18-f37072fd.source.json`.

## Реальное обучение и test

Сетевые DNS/timeout ошибки преодолены: полный набор зависимостей установлен. `pip check` — `No broken requirements found`. Реестр **70** установленных пакетов и notices находится в `artifacts/licenses/`, точный snapshot окружения — `artifacts/environment-py312.txt`.

`python -m scripts.inspect_dataset` выполнен: 42 строки, нет пропущенных видео, некорректных timestamps или ошибок; обе группы одинакового содержимого перечислены в `artifacts/dataset_inspection.json`.

`python -m ml.training train` реально выполнен на **24 уникальных train-видео, 283 размеченных окнах**, без weak negatives. Использованы официальные ResNet18 weights, torch 2.6.0+cpu, torchvision 0.21.0+cpu, sklearn 1.6.1. Веса, joblib pipeline и metadata сохранены в `models/`. Threshold **0.0479978732** выбран только по video-F1 на 8 validation-видео.

`python -m ml.training evaluate` выполнен отдельно на 8 test-видео, не использованных при обучении. Модель после просмотра test не изменялась.

| Метрика | Video level | Window level |
|---|---:|---:|
| Precision | 0.500 | 0.217 |
| Recall | 1.000 | 0.833 |
| F1 | 0.667 | 0.345 |
| ROC-AUC | 0.625 | 0.567 |

Video confusion matrix `[[TN, FP], [FN, TP]] = [[0, 4], [0, 4]]`. **Все четыре нормальных test-видео ошибочно отмечены как подозрительные.** Это слабый экспериментальный baseline; его нельзя представлять как надежный банковский детектор. Средняя ошибка локализации 4.0 секунды по четырем размеченным событиям, условно при наличии предсказанного события; это не отдельное доказательство качества локализации и не one-to-one event matching. Полный отчет — `artifacts/test_metrics.json`.

## API и время

Через FastAPI TestClient с настоящим subprocess worker выполнены два полных анализа, включая загрузку моделей и, при положительном результате, извлечение JPEG:

| Видео | Длительность | Verdict модели | Полное время | Evidence |
|---|---:|---|---:|---:|
| Х-14 (самое длинное в наборе) | 142.53 с | no_violation | 29.25 с | 0 |
| X-2 | 17.07 с | violation | 14.15 с | 1 событие, 3 JPEG |

Три JPEG из положительного API-ответа реально декодированы обратно OpenCV. Ответы сохранены локально в `artifacts/api_smoke_result.json` и `artifacts/api_positive_result.json`. Число событий — результат модели, не подтверждение фактического нарушения. Оба замера менее 5 минут на текущем CPU, но это не SLA для произвольного оборудования/видео. Время upload и очереди не включено.

Uvicorn реально запущен на `127.0.0.1:8000`, `/health` отвечает и подтверждает наличие файлов модели и настроенного ключа. Streamlit запущен на `127.0.0.1:8501`, HTTP health отвечает `ok`; через Streamlit AppTest проверены начальный экран и отображение настоящего положительного результата с тремя JPEG, без исключений. `.env` создан со случайным локальным ключом, который не выводился в лог.

Не выполнены: отдельный прогон на Python 3.11, CUDA, Docker build/run, ручная оценка UX в браузере и промышленная валидация качества. Код не делает юридических выводов, нормативы пусты. Коммерческие условия предобученных весов требуют отдельной проверки, описанной в `LICENSES.md`.
