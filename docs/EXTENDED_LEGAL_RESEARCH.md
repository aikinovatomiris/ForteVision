# Передача backend-команде

Дата правового среза — 18.10.2026. Это новая база рядом с исходными файлами; действующий сервис и ML-pipeline не изменены.

Загрузить совместно:

- [rules_extended.json](../research/rules_extended.json) — 26 записей, условия и исключения; все детекторы отключены.
- [legal_sources.json](../research/legal_sources.json) — источники, точные выдержки, происхождение и ограничения свежести.
- [ml_rule_mapping.json](../research/ml_rule_mapping.json) — обязательные признаки, версии и контракт доказательств.
- [ui_explanations.json](../research/ui_explanations.json) — индивидуальные русские шаблоны и нейтральный fallback.

[legal_research_extended.md](../research/legal_research_extended.md), [coverage_matrix.md](../research/coverage_matrix.md) и [research_changes.md](../research/research_changes.md) объясняют юридические решения и миграцию. Для R01–R05 сохранены ID и `event_type`, однако новые условия и версия 2.0.0 требуют повторной привязки адаптеров. Старая проверка `norm_basis == "direct"` также должна быть пересмотрена: новый потребитель использует результат аудита и область применимости, а не единственную строку старого статуса.

Пример интерпретатора `research/explain_local.py` и скрипт `research/validate_research.py` находятся только в исходном архиве; в эту документационную ветку они не перенесены. Поле `reference_module` в каталоге описывает этот архивный пример, а не доступный модуль проекта. Интеграция и реализация контракта требуют отдельного изменения кода.

Не принимать `release_registry`, результаты проверки доказательств или разрешение на включение из ответа модели/клиентского HTTP-запроса. Хеш `binding_hash` совместим по алгоритму с прежней привязкой; дополнительно `knowledge_hash(catalog)` покрывает весь каталог, включая машинные предикаты. После изменения любого содержания каталог требует нового допуска. Реестр выпуска привязывается к конкретной версии модели и локальному отчёту оценки; наличие строки с именем файла само по себе не является проверкой качества — реестр выпуска создаёт команда после проверки отчёта.

Для публикации нужны одновременно `enabled_for_detection=true`, действующий серверный допуск, все обязательные признаки, явно отсутствующие исключения и проверенные локальные доказательства. `candidate` означает только возможное нарушение для проверки. Сервер преобразует `evidence_frame_refs` в 1–3 настоящих JPEG base64 и сериализует прежние `type`, `timecode_sec`, `description`, `evidence_frames`. Экранировать тексты при выводе HTML. Не добавлять в публичный объект внутренние состояния.

Сохранить `POST /api/v1/analyze`, `GET /api/v1/jobs/{job_id}`, `X-API-Key` и два значения verdict. Подавление одного события не означает `no_violation` для всего ролика. При выключенном каталоге нельзя сообщать об успешной проверке видео: обработчик задания сообщает предусмотренную сервисом неготовность/ошибку. После полноценного валидированного анализа без прошедших правила событий используется `no_violation`; это не юридический сертификат отсутствия всех возможных нарушений.

Проверка синтаксиса четырёх основных JSON из корня репозитория:

```powershell
python -c "import json; from pathlib import Path; names = ('rules_extended.json', 'legal_sources.json', 'ml_rule_mapping.json', 'ui_explanations.json'); [json.loads((Path('research') / n).read_text(encoding='utf-8')) for n in names]; print('JSON OK')"
```

Тесты, описанные в исходном архиве, используют только синтетические структуры; при этом переносе они не запускались. Проверки импорта описаны ниже. Они не подтверждают точность модели, не читают банковские видео и не дают основания включать детекторы. Перед выпуском нужны отдельные локальные проверки категорий, исключений, таймкодов, доказательных кадров и новых ракурсов. В исходном архиве заявлены адаптеры для R01–R05, но их соответствие версии 2.0.0 и качество ещё требуется подтвердить; для остальных потенциальных правил адаптеры не реализованы в рамках этой работы.

## Состав переноса в командный репозиторий

Источник: `forte_legal_extended_2026-10-18.zip`. Семь основных исследовательских файлов и пять файлов в [research/sources](../research/sources/) перенесены побайтно. Исторические даты и выводы автора архива сохранены; это не новая правовая экспертиза при импорте.

Рабочая база ветки — `origin/main` на коммите `2c69c80`. Существующие `research/rules.json`, `configs/rules.json`, `research/report.html` и код приложения не заменяются. Расширенный каталог не подключается к сервису автоматически.

Ссылки на `_baseline/`, `team_handoff/`, `local_review/`, старые ZIP и `forte_research_2026-10-17/` внутри исходного исследования описывают прежнюю рабочую папку автора. Фраза об отсутствии `report.html` относится к той папке; в командном репозитории файл существует и сохранён. Эти исторические пути и список `artifacts` в baseline-аудите не являются обещанием наличия файлов в этой ветке. Два официальных текстовых снимка, все пять `source_artifacts` и все используемые `snapshot_path` расширенного каталога включены и проверены по SHA-256. Вложенные архивы, код генерации/детекторов и локальные отчёты из исходного пакета не публикуются.

Видео, кадры, приватная разметка, ключи API, `.env` и веса моделей не включены. Инструкции интеграции выше предназначены для отдельной будущей работы команды.

## Проверки импорта

- [Отчёт импорта](../research/import_validation_2026-10-18.json): строгий разбор JSON, уникальность и согласованность ID, обязательные поля, хеши цитат и привязок, сохранность исходных файлов, проверка состава публикации.
- [Проверка внешних ссылок](../research/sources/link_check_2026-10-18.json): URL извлечены из всех двенадцати перенесённых файлов и проверены HTTP GET с ограничением времени. HTTP 200 для страницы, требующей JavaScript, не подтверждает содержимое или редакцию акта. Ошибки доступа и таймауты записаны отдельно; архивный журнал проверки не перезаписывается.
- Упоминания исторических путей оставлены как сведения о происхождении. Рабочие Markdown-ссылки этой инструкции и ссылки на локальные снимки проверяются отдельно.

Все 26 записей сохраняют `enabled_for_detection=false`. Проверки импорта не измеряют качество ML и не разрешают включать детекторы.
