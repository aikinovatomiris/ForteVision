# Пересборка обучения по временной разметке, 18.10.2026

Текущая конфигурация: `models/anchored_v3.joblib`, **только экспериментальные гипотезы для ручного просмотра**. Автоматическая проверка качества не пройдена. Старые модели сохранены. Это не готовый точный детектор для жюри.

## Источник и исправление

Использована новая таблица `data/raw/fortevis_%D0%BD%D0%B0%D1%80%D1%83%D1%88%D0%B5%D0%BD%D0%B8%D1%8F.xlsx` (SHA-256 `4f81595728ee003073ace7cfeaa0ec05693abc5d21a9d78ff0aa37b9376f6330`). Бинарные метки новой таблицы совпадают с исходным manifest/open_labels для всех 40 уникальных видео. Неверным было прежнее дополнительное сопоставление описаний и типов, использованное recovery-моделями. Их результаты нельзя сравнивать с новыми числами как результаты одной и той же разметки.

19 отметок отдельных действий вручную перенесены из текста в локальный `data/raw/temporal_annotations_v2.json`. Для каждой сохранены строка и описание источника. SHA исходного XLSX проверяется до обучения. Исходные файлы не изменялись. X-4/Х-47 и X-5/Х-48 — дубликаты, не независимые примеры. У X-4 выделены разные действия около 32 и 57 секунд; 57 и 68 относятся к последовательности с деньгами предыдущего клиента, а не двум независимым учебным видео.

X-32, X-33, X-34, X-38, X-40 не имеют новых точных временных отметок. Они не дают положительных окон для обучения. Их бинарные метки используются для оценки видео; отсутствие времён не подменено старой разметкой. Отметки — приблизительные моменты, а не размеченные начала/концы действий.

## Метод

Локальный замороженный ResNet18, весь кадр с сохранением пропорций, 2 кадра/с, окна 4 с, шаг 2 с. Признаки mean/max; дополнительно сравниваются изменения до/после окна и относительно медианы видео. В `relative` исключён блок абсолютного внешнего вида, чтобы уменьшить зависимость от комнаты и одежды. Предсказание не получает имя видео, его номер, хеш или текст Excel.

Отдельный бинарный LogisticRegression и независимые бинарные классификаторы типов позволяют обнаружить несколько действий, в том числе в одном окне. Положительное окно находится в пределах 2,1 с от отметки по реальному sampled timestamp. Нормальные ролики дают отрицательные окна. Остальные участки положительного видео неизвестны. Дополнительный эксперимент использует только участки более чем за 10 с **до первого** отмеченного события как слабые отрицательные с весом 0,15. После события нормальность не предполагается: опасное состояние может сохраняться.

StandardScaler обучается внутри каждого fold. Связанные сценарные записи консервативно сгруппированы по описаниям; истинных ID съёмочных сессий нет. Исходные восемь test ID сохранены вне обучения. Связанные с ними X-3, X-11, X-12, X-17, X-24, X-27 тоже исключены из обучения. Development: 26 видео, из них 22 пригодны для обучения окон. Подбор признаков, регуляризации и порога выполняется по трём групповым folds. В каждом из них исключены целые группы, а не отдельные окна.

v2: выбор по video F1. v3: дополнительное сравнение относительных признаков и слабых отрицательных, выбор с приоритетом ограничения FP и F0.5. Желаемое ограничение ложных тревог не достигнуто. Выбран v3: relative, C=0.1, threshold=0.8, weak weight=0.15. Порог типа 0.6 фиксирован. Оценки классификаторов не являются калиброванными вероятностями.

## Реальные результаты

v3 grouped OOF (использован для выбора, это не независимая итоговая оценка): TP=13, FN=1, FP=7, TN=5; precision=0.65, recall=0.929. Из 12 размеченных событий 6 сопоставлены по времени в пределах ±5 с, только 1 одновременно по времени и типу.

v3 на восьми отложенных видео: TP=4, FN=0, FP=4, TN=0. Таким образом, сигнал выдан **на каждом видео**; полнота 100% здесь не свидетельствует о полезном различении классов. Из четырёх событий с новыми временными отметками два найдены в пределах ±5 с, ни одно одновременно с правильным типом. Для X-40 нет новой временной отметки, и он не входит в знаменатель оценки времени. Средняя ошибка 1,47 с вычислена лишь на двух совпавших событиях и не отражает пропуски/ложные события. Всего предсказано 14 событий на восьми видео.

v2 также выдал сигналы на всех восьми видео. После просмотра v2 была проведена дополнительная итерация разработки v3; это ранее исследованный внутренний test, не новая слепая проверка. Ни веса, ни пороги напрямую по test не подбирались. Для окончательной независимой оценки нужны новые записи.

Автоматический release gate не пройден обеими моделями. `review_only=true`: результаты находятся в `review_candidates`, а не в подтверждённых `violations`. Совместимый `verdict=no_violation` здесь означает отсутствие автоматического finding; это **не утверждение нормальности видео**. Смотреть `assessment_status`, `analysis_complete`, предупреждение UI. Такой режим не готов для автоматической оценки жюри по двум вердиктам.

## Описания и research

Описание — шаблон предсказанного визуального типа, не свободный рассказ и не поиск ответа по номеру файла. Из пяти исследовательских сценариев явно представлены R02 (деньги предыдущего клиента) и R04 (помещение без наблюдаемого пересчёта). Наличие примера не означает надёжное распознавание. Другие визуальные категории таблицы не объявляются автоматически доказанными нарушениями законодательства. Источники добавляет существующий проверяемый механизм `app/rule_links.py`; research не используется как доказательство того, что событие произошло.

Для большинства типов есть только один независимый обучающий ролик. Для некоторых типов проверочных видео обучающих примеров нет. Поэтому точные описания новых видео пока ненадёжны, даже если учебные ролики воспроизводятся хорошо.

## Воспроизведение

Из корня проекта, PowerShell, без загрузки весов из интернета:

```powershell
.\.venv\Scripts\python.exe -m scripts.train_anchored --workbook 'data/raw/fortevis_%D0%BD%D0%B0%D1%80%D1%83%D1%88%D0%B5%D0%BD%D0%B8%D1%8F.xlsx' --annotations data/raw/temporal_annotations_v2.json --name anchored_new --objective precision
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
.\.venv\Scripts\python.exe -m scripts.serve
```

Существующий файл модели не перезаписывается: нужен новый `--name`. Нужны исходные видео, manifest, локальные веса, JSON разметки . Кеш признаков проверяет хеш видео, весов и sampling. Приватная разметка, видео, модели и отчёты исключены из Git.

Отчёты: `artifacts/anchored_v3/data_audit.json`, `selection.json`, `test_evaluation.json`, `release_gate.json`, `smoke_api.json`. API smoke использовал реальный X-4 с переименованной загрузкой, новый worker, настоящие JPEG, валидацию JSON и cleanup; 19,19 с, два события 32,03 и 58,03 с. X-4 обучающий: этот результат не метрика обобщения.
