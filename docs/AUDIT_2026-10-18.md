# Проверка ForteVision — 18.10.2026

## Главный результат

Локальная цепочка загрузки, анализа и выдачи evidence работает. Классификатор обучен и подключён, но качество недостаточно для сдачи как надёжного детектора. Типы событий и нормативные ссылки не обучены и не активированы.

## Проверено на этом ПК

- 43 теста: passed, 2 предупреждения (Starlette/httpx и sklearn/SciPy).
- Реальный POST /api/v1/analyze и GET /api/v1/jobs: done за 9.53 с, 1 событие, 3 валидных JPEG (X-1, проверка работоспособности, не качества).
- Offline inference с блокировкой внешних Python-соединений: 7.90 с. Сетевая изоляция средствами ОС в этом прогоне не проверялась.
- pip check: конфликтов зависимостей нет.
- 42 видео и Excel побайтно совпадают с архивом Downloads/open.zip.
- После объединения точных дубликатов: 40 видео. Новый фиксированный split: 24 train / 8 validation / 8 test. Он отличается от старого sklearn split из исторического README; сравнивать старые и новые метрики напрямую нельзя.

## Качество подключённой модели

ResNet18, полный кадр 320×320 с сохранением пропорций и дополнением полей, 2 кадра/с, окна 4 с с шагом 2 с, ridge-классификатор с балансировкой веса видео. Порог и регуляризация выбраны только на validation. Сравнены центральная обрезка, полный кадр, полный кадр с вычитанием медианного контекста. По F1 все три варианта одинаково слабы; полный кадр выбран по меньшей условной ошибке локализации на validation до просмотра test.

| Набор | Precision | Recall | F1 | TN / FP / FN / TP |
|---|---:|---:|---:|---|
| Validation (8 видео) | 0.50 | 1.00 | 0.667 | 0 / 4 / 0 / 4 |
| Test (8 видео) | 0.429 | 0.75 | 0.545 | 0 / 4 / 1 / 3 |

Test: средняя ошибка ближайшего предсказанного пика 29.75 с только по найденным положительным событиям; пропуск X-2 не включён в эту среднюю. Это плохой результат. Четыре отрицательных видео дали ложные тревоги. После просмотра test параметры не менялись. Не подбирать дальнейшие параметры по этому test и не объявлять его независимым для следующих итераций.

Отчёты: `artifacts/fullframe_classifier_test_metrics.json`, `artifacts/current_api_smoke.json`, `artifacts/current_offline_verification.json`.

## Изменения

- `ml/quick_train.py`: автономное обучение, кэш признаков, равный вес роликов внутри класса, подбор регуляризации/порога на validation, отдельная test-оценка. Кэш содержит производные от обучающих видео данные; хранить локально по правилам дататона.
- `ml/detection.py`: необязательный full_frame; прежний center сохранён.
- `ml/pipeline.py`: режим изображения берётся из metadata; неподдерживаемый режим отклоняется.
- `tests/test_quick_train.py`: сохранение/загрузка классификатора, контекстная инвариантность, сохранение объектов у края кадра.
- Скачаны официальные ResNet18 weights, проверен SHA-256. Это предобученный визуальный extractor, не банковский детектор.
- `models/classifier.joblib` и `.json`: экспериментальная копия `fullframe_classifier` для штатного API. Версии других кандидатов сохранены.

## Запуск

Из папки ForteVision:

```powershell
.\.venv\Scripts\python.exe -m scripts.serve
```

UI: http://127.0.0.1:8501 ; API: http://127.0.0.1:8000 . Ключ берётся из существующего .env; он не менялся и не выводился в отчёты.

Фактически проверенное окружение: Python 3.13.14, torch 2.14.1+cpu, torchvision 0.29.1+cpu. GTX 1660 доступна аппаратно, но установленный torch не использует CUDA. Созданное `.venv312` не доустановлено из-за медленной загрузки; не использовать его для запуска. Старые requirements/pyproject описывают другую комбинацию Python/torch; снимок фактических версий — `artifacts/current_environment.json`. Запуск выше использует проверенное существующее окружение, а не pip install проекта.

4. Проверить переносимость на новом ракурсе, лицензионные условия весов и данных.
5. Развернуть публичный HTTPS URL/API и проверить доступ жюри. Локальный адрес этого не заменяет.

Победа и качество не гарантированы; текущая модель — работающий эксперимент для дальнейшей разработки.
