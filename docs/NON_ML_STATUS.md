# Готовность вне ML

Реализовано: единый запуск, local inference guard, точные формулировки вердиктов, двухшаговый API, настоящие JPEG с валидацией, readiness, общий deadline загрузка+очередь+анализ, ограниченная очередь, сохранение результатов в SQLite, восстановление interrupted jobs как failed, TTL/вытеснение/удаление, single-owner lock, готовый HTTPS proxy/Compose, скрипт проверки жюри и интерфейс нормативных ссылок.

Не следует считать автоматически закрытыми:

| Вопрос | Что ещё требуется |
|---|---|
| Публичный URL | Домен/сервер/доступ от команды, запуск и проверка извне |
| Целевая инфраструктура | Docker build/run проверен локально на Python 3.11.17; повторить smoke-test на сервере команды |
| Offline-изоляция сервера | Реальный inference проверен с Docker --network none; для публичного сервера отдельно настроить исходящий firewall, сохранив входящий API |
| Успех каждого видео < 5 минут | Измерение на целевой машине; timeout — ошибка, не успешный анализ |
| Коммерческие права | Подтверждение конкретных pretrained-весов, notices и условий передачи собственного кода; не заменяется техническим документом |
| Типы, описания и применимость нормативов | Валидированный ML-релиз от разработчика; нельзя подделать на стороне UI/backend |

Исследование нормативов лежит в research; утверждённый runtime-каталог configs/rules.json пока пуст. Адаптер готов, но этот факт не делает research-сценарии распознаваемыми. Ни точность, ни отсутствие переобучения доработками инфраструктуры не заявляются.
